# Local session archive MVP
User requirements: archive Codex and Claude Code CLI/Desktop sessions locally, JSON CLI similar to constulto, extensible agents. No remote backend, automatic AI analysis or scheduler in this iteration.
Proposal: Python stdlib sqlite3/argparse, executable prospabitus, sync/status/sessions list/show/search/events/changes/export/doctor/skill show. Named profiles select independent SQLite files; explicit source roots or default CODEX_HOME and CLAUDE_CONFIG_DIR. Product adapters discover files and normalize metadata/messages, retaining all raw JSONL records including unknown types. Desktop/CLI provenance retained rather than separate parsers. Tools and instructions excluded from default search; explicit all-events mode.
Storage: immutable complete-prefix file snapshots in SQLite BLOBs, SHA256; logical stream identity agent + native session ID + subagent filename if applicable. Active snapshot may only advance by byte-prefix extension; shorter known prefixes are ignored. Divergent replacements are archived as conflicts without replacing active text, reported as sync failure. No source deletions propagate. Complete newline-terminated records only; incomplete trailing bytes deferred. Malformed complete records fail that file with diagnostics. Each snapshot, normalized events, active pointer and monotonic change row commit atomically. SQLite BEGIN IMMEDIATE serializes writers. Snapshot/events addressed by revision so changes remain readable after later updates. Bounded row and text pagination; raw export explicitly writes exact archived bytes to a named destination. JSON stdout, structured errors and nonzero exit codes.
MVP tradeoffs: whole-file reads/storage on changed files, literal Unicode substring search instead of FTS, no attachment binary collection (references retained), conflict resolution deferred and reported. No guess that role=user means human. Human origin unknown unless source proves it. Parsing supported current local schema and synthetic representative fixtures; tests cover both origins, append, duplicates, partial writes, conflicts, changes, bounds, CLI and Japanese search.
