# Go migration design
User explicitly requested replacing Python with Go and using constulto as reference for project structure and CI. Preserve the existing JSON CLI, raw snapshots, SQLite v1 DB compatibility, IDs/cursors, provenance and the working local archive. No remote writes, release/tag/push/deploy or real transcript transmission is requested.
Proposed Go module github.com/rokoucha/prospabitus. cmd/prospabitus main handles signals; internal/cli Kong (as constulto), internal/agent product adapters, internal/archive SQLite+queries; assets embeds agent Skill. Direct dependencies Kong v1.17.0 and modernc.org/sqlite v1.61.0 (CGO-free cross compilation); Go 1.26.0 minimum (confirmed from the pinned SQLite module). Keep existing schema including 0-based JSONL line numbers, UTF-8 Unicode code-point offsets, default filtering and JSON envelope. Stream identity, unknown origins, mirror occurrence matching, copied context and immutable revision IDs remain compatible. JSON object tool formatting may be compact but parse-equivalent; normalize legacy formatting for comparison tests. BEGIN IMMEDIATE and busy timeout with a single connection per store; publish export only after private temp fsync/close via non-overwrite hard link.
Minimal improvements necessary for Go: decoding JSONL without Scanner's default 64K line limit, reject wrong types instead of panics, use context for DB/long scans, preserve DB/file modes and no-follow discovery. Existing v1 archives open directly; no reimport or DB rewrite necessary. Validate all saved raw revisions by comparing Go metadata/events with Python-produced projections locally; never transmit that corpus to reviewer. Unit tests use existing sanitized fixtures + synthetic regressions; read existing real archive, compare queries/export, and fresh import to temporary new local validation DB if useful. Python code is removed after parity verification; tests/tooling runtime all Go.
CI mirrors constulto: SHA-pinned checkout/setup-go, gofmt check, go test -race ./..., go vet ./..., CGO_ENABLED=0 go build ./cmd/prospabitus. Test Ubuntu and macOS. Release workflow verifies first, uses tagpr and GoReleaser with darwin/linux amd64/arm64 archives and checksums. Do not enable Homebrew publication requiring an unprovisioned secret; document optional addition later. No actual publication now. Copy only reusable CI configuration; no dependency on constulto or unrelated features. Add renovate same style for Go/actions updates. No license choice inferred from another repo.
